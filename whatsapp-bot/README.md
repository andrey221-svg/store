# 🤖 בוט וואטסאפ - עוזר אישי שמזמין בשבילך

כותבים לבוט בוואטסאפ מה צריך, והוא עושה את זה באינטרנט:

- 🍕 מזמין אוכל ממסעדות: מוצא מסעדה, בונה סל ומכין הזמנה באתר או באפליקציה
- 🔎 מחפש מידע: שעות פתיחה, מחירים, תפריטים, טלפונים וביקורות
- 🛒 משווה מחירים ומוצא מוצרים, וגם מבין תמונה ששולחים לו
- 💬 שולח הודעת וואטסאפ לעסק בשמך, למשל הזמנת שולחן, ומעביר אליך את התשובה
- 🧠 זוכר את הכתובת, השם, האלרגיות והמסעדות שאתה אוהב

**לפני כל תשלום, הזמנה או הודעה לעסק, הבוט שולח לך סיכום ומחכה שתענה "מאשר".**
זה לא רק הנחיה למודל: הקוד עצמו חוסם לחיצה על כפתורי תשלום ושליחת הודעות בלי האישור שלך.

הבוט לא מקליד מספרי כרטיס אשראי לעולם.
הוא משתמש באמצעי התשלום ששמור אצלך בחשבון באתר.
אם אין כזה, הוא שולח לך קישור כדי שתשלם בעצמך.

---

## מה צריך

- מחשב שנשאר דלוק, או שרת קטן בענן. אפשר גם Windows או Mac.
- תוכנת Node.js בגרסה 20 ומעלה, מהאתר nodejs.org
- מפתח API של Claude. יוצרים אותו בכתובת https://platform.claude.com/settings/keys (השימוש בתשלום, ראו "עלויות" למטה)
- חשבון וואטסאפ. **מומלץ מספר נפרד לבוט**, כמו סים נוסף או מספר וירטואלי. הסבר בהמשך.

---

## התקנה, פעם אחת

פותחים טרמינל (ב-Windows: PowerShell) בתיקייה `whatsapp-bot` ומריצים:

</div>

```bash
npm install
npm run setup
cp .env.example .env
```

<div dir="rtl">

הפקודה השנייה מתקינה את הדפדפן שהבוט משתמש בו.
ב-Windows אפשר להעתיק את הקובץ `.env.example` ל-`.env` ידנית.

עכשיו פותחים את הקובץ `.env` בעורך טקסט וממלאים את המפתח:

</div>

```ini
ANTHROPIC_API_KEY=sk-ant-...
```

<div dir="rtl">

### בוחרים איך לחבר את הוואטסאפ

**אפשרות א' - מספר נפרד לבוט (מומלץ):**
מחברים את הבוט לוואטסאפ של המספר הנוסף.
בקובץ `.env` כותבים את המספר האישי שלך, כדי שרק אתה תוכל לתת לו פקודות:

</div>

```ini
OWNER_NUMBER=0541234567
```

<div dir="rtl">

אחר כך פשוט שולחים לבוט הודעות כמו לכל איש קשר.

**אפשרות ב' - הוואטסאפ שלך עצמו:**
משאירים את `OWNER_NUMBER` ריק, ומחברים את הבוט לוואטסאפ שלך.
כותבים לבוט בצ'אט "הודעה לעצמי" שלך. הבוט מתעלם מכל שאר השיחות שלך.

## הפעלה

</div>

```bash
npm start
```

<div dir="rtl">

בפעם הראשונה יופיע ברקוד בטרמינל.
בטלפון של המספר שהבוט מתחבר אליו נכנסים לוואטסאפ, ואז הגדרות, מכשירים מקושרים, קישור מכשיר, וסורקים.

בשרת בלי מסך נוח יותר להתחבר עם קוד צימוד במקום ברקוד. כותבים ב-`.env` את מספר הבוט:

</div>

```ini
PAIRING_NUMBER=0501234567
```

<div dir="rtl">

בהפעלה יודפס קוד של 8 תווים.
בוואטסאפ בוחרים מכשירים מקושרים, קישור מכשיר, ואז "קישור עם מספר טלפון".

החיבור נשמר. בהפעלות הבאות לא צריך לסרוק שוב.

## איך משתמשים

דוגמאות להודעות:

- תזמין לי פיצה משפחתית עם זיתים מהפיצרייה הכי טובה באזור
- מה פתוח עכשיו לסושי עם משלוח לרמת גן?
- תזכור שהכתובת שלי היא הרצל 10 דירה 5, קומה 2
- תשלח למסעדה הזאת הודעה שאני רוצה שולחן ל-4 מחר ב-20:00
- כמה עולה המוצר הזה? (עם תמונה)

כשהבוט מוכן לבצע, הוא שולח סיכום.
עונים **מאשר** כדי לבצע, או **בטל** כדי לבטל.
אם כותבים משהו אחר, הבקשה מתבטלת והבוט יכין סיכום חדש.

פקודות:

- **חדש** - מתחילים שיחה חדשה
- **עצור** - עוצרים משימה באמצע
- **עזרה** - רשימת האפשרויות

## ⚠️ חשוב לדעת על החיבור לוואטסאפ

הבוט מתחבר דרך "מכשיר מקושר", כמו וואטסאפ ווב, בעזרת ספרייה לא רשמית.
וואטסאפ לא מאשרת רשמית חיבורים כאלה, ויש סיכון שהמספר ייחסם.
בשימוש אישי ושקט הסיכון נמוך, אבל הוא קיים.
**לכן מומלץ מספר נפרד לבוט ולא המספר הראשי שלך.**

אתרים שונים בנויים אחרת, ולפעמים הבוט לא יצליח להשלים הזמנה לבד.
במקרה כזה הוא ישלח לך את מה שמצא, עם קישור או מספר טלפון.

## הרצה בשרת, כדי שיעבוד גם כשהמחשב כבוי

יש קובץ Docker מוכן. חשוב לחבר דיסק קבוע לתיקייה `/app/data`, כי שם נשמרים החיבורים והשיחות.

</div>

```bash
docker build -t whatsapp-bot .
docker run -d --name whatsapp-bot --restart unless-stopped \
  --env-file .env -v $(pwd)/data:/app/data whatsapp-bot
docker logs -f whatsapp-bot
```

<div dir="rtl">

בפקודה האחרונה רואים את הברקוד, או את קוד הצימוד.
אותו קובץ Docker עובד גם בשירותים כמו Railway, Render או Fly.io. שם צריך להוסיף Volume לתיקייה `/app/data`.

## איפה נשמר מה

הכול נשמר בתיקייה `data/`, שלא עולה ל-git:

- חיבור הוואטסאפ
- החיבורים שלך לאתרים
- השיחות
- הפרופיל שלך: כתובת, העדפות

כדי לנתק את הבוט מוואטסאפ: מוחקים את `data/whatsapp-auth`, או מנתקים אותו בטלפון תחת מכשירים מקושרים.

## תקלות נפוצות

**"Logged out" -** הבוט נותק מוואטסאפ. מוחקים את `data/whatsapp-auth` ומריצים שוב.

**הבוט לא עונה -** בודקים ש-`OWNER_NUMBER` הוא המספר שממנו אתה כותב. אם הוא ריק, כותבים בצ'אט "הודעה לעצמי".

**"מפתח ה-API לא תקין" -** בודקים את `ANTHROPIC_API_KEY` בקובץ `.env`.

**שגיאה של הדפדפן -** מריצים שוב `npm run setup`. בשרת לינוקס בלי Docker מריצים:

</div>

```bash
npx playwright install --with-deps chromium
```

## מבנה הקוד

</div>

```
src/index.js       entry point - connects WhatsApp
src/whatsapp.js    WhatsApp connection (Baileys): owner detection, images, forwarding business replies
src/assistant.js   commands, approval replies, per-chat queue
src/agent.js       Claude tool loop, conversation history, system prompt
src/tools.js       browser / approval / messaging / memory tools
src/approvals.js   the approval gate and payment-button / card-number detection
src/browser.js     Playwright browser with a persistent profile
src/cli.js         terminal mode for testing
src/login.js       opens the browser profile to log in to sites
```
